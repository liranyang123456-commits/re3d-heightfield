# Pseudo-3D Heightfield Reconstruction from Monocular Endoscopic Video

Code, evaluation scripts, and result files for the manuscript

**Pseudo-3D Heightfield Reconstruction from Monocular Endoscopic Video via Gradient-Anchored Geometric Constraints**

submitted to *Computerized Medical Imaging and Graphics* (CMIG, Elsevier).

**Repository:** https://github.com/liranyang123456-commits/re3d-heightfield

This repository does **not** claim an overall state-of-the-art ranking. Each protocol answers a different question (shape, metric scale, aligned depth, cross-hardware generalization). See `paper/paper_cmig.tex` Section *Protocol-Aware Summary* and `figures/fig_sota_summary.pdf`.

## Reproducibility notes

- Random seed `42` is used only for PCA sub-sampling.
- Chessboard pose table uses the first 50 frames and an independent `solvePnP` reference (`8×5` inner corners, `5.0` mm squares).
- EndoNeRF AbsRel `0.0285` is the 100-frame (50+50) median-aligned protocol, not the full 217-frame mean (`≈0.0279`).
- SCARED / stereo-lap depth of the classical pipeline equals Stereo SGM by construction.
- Ablation point counts `8421/14892/16803` and the `61.5 s` runtime are archived numbers; they are not regenerated by the scripts in this repository.
